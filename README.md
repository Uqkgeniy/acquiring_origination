# Аналитика воронки подключения мерчантов в интернет-эквайринге

> Учебный проект. Данные синтетические, сгенерированы скриптом `generate_data.py`.

Воронка подключения (Origination): путь мерчанта от заявки до первого платежа. На каждом шаге часть клиентов теряется. Цель проекта: найти, где и почему, и предложить, что менять.

## Бизнес-контекст

Банк дает бизнесу прием онлайн-платежей (интернет-эквайринг). Мерчант приносит комиссию только после первого платежа, поэтому воронка доводится до активации, а не до подписания договора.

Этапы: `lead` - `qualified` - `application` - `kyc_passed` - `contract_signed` - `integration_done` - `test_payment` - `first_payment`.

## Данные

30 000 вымышленных мерчантов, заявки с 1 января по 29 сентября 2026. Три файла в папке `data/`:

| Файл | Содержание |
| --- | --- |
| `merchants.csv` | Атрибуты мерчанта (канал, размер, платформа сайта, регион, сейлз) и итог |
| `stage_events.csv` | Время достижения каждого этапа воронки |
| `sales_reps.csv` | Справочник сейлзов |

Описание колонок: [docs/data_dictionary.md](docs/data_dictionary.md).

## Как запустить

```
pip install -r requirements.txt
python generate_data.py
```

Скрипт создаст папку `data/` с тремя CSV. Дальше открывай ноутбуки из папки `notebooks/`.
